# 🎙️ EchoAgent AI
> **Transform Voice into Actionable Automated Workflows**

EchoAgent AI is a real-time voice-to-action platform designed to capture audio, transcribe spoken intent using AssemblyAI, and automatically convert voice commands into structured workflows—including summaries, action items, reminders, and external API integrations.

---

## ✨ Key Features

* **⚡ Real-Time Voice Processing:** Powered by AssemblyAI's speech intelligence engine.
* **🎯 Dynamic Niche Modes:**
  * **💼 Meeting Mode:** Automatically extracts key summary points, participant tasks, and calendar events.
  * **🚨 SRE Incident Mode:** Detects system outages, tags critical infrastructure issues, and triggers webhooks/alerts.
  * **📝 Content Strategy Mode:** Brainstorms creative copy, updates Notion workspaces, and schedules posts.
* **🎨 Neon Glassmorphism UI:** Built with React & Tailwind CSS for a modern, high-contrast dark aesthetic.
* **⚡ Instant Action Engine:** Displays live audio visualizers and step-by-step action plan execution cards.

---

## 🛠️ Tech Stack

* **Frontend:** React.js, Tailwind CSS (v4), Lucide React (Icons)
* **Build Tool:** Vite
* **Voice Engine:** AssemblyAI API / Web Speech API Integration
